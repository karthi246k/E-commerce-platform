# Velora 

## Overview

Velora is a full-stack e-commerce platform built to provide a seamless online shopping experience with product browsing, authentication, cart management, and responsive design. The project focuses on building scalable frontend-backend communication using REST APIs.

---

## Source Code Notice 

Source code is private and not publicly available.

This repository is intended for showcasing project features, screenshots, and documentation only.

---

## Features 

* User authentication (Login / Register)
* Product listing and browsing
* Product attribute selection
* Shopping cart management
* Responsive UI design
* REST API integration
* Dynamic product pages
